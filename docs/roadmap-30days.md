# AI Agent 开发实习 · 30 天冲刺路线

> 起点：2026-10-20（周二）｜目标：11 月中下旬开始投递 AI Agent 开发日常实习
> 每日有效时间假设 6-8 小时。若某天只有 3 小时，优先保「当日产出物」，阅读可顺延。

---

## 零、先把战略定死

### 1. 岗位线：只走「开发 / 工程线」，不要碰算法线

- 算法实习岗（大模型算法实习生）你要跟有顶会、有导师团队的科班硕博竞争，你没有论文、没有团队，一个月内补不上。
- 开发 / 工程实习岗的评价标准是「能不能把系统搭起来、讲清楚、跑得稳」——这个一个月能做到。
- 你要投的 JD 关键词：`AI Agent 开发实习生`、`LLM 应用开发实习生`、`RAG 工程师实习`、`AI 工程实习生`、`大模型应用开发`。
- 看到 `大模型算法实习生`、`LLM 训练`、`RLHF / RL / GRPO` 这类 JD，直接跳过。

### 2. 你的处境：劣势没你想的那么大，优势你还没意识到

**劣势**：起步晚约 3 周；手上两个项目不能直接用于面试。

**优势（这几条你同学未必有，也是招实习生最稀缺的）**：

- **可长期实习**：大四 + 研一期间都没课，能干 8-12 个月。招实习生的团队最怕刚教会就走。
- **随时到岗、每周 5 天、北京可现场面试**。
- **985 硕士拟录取**：学历筛选这关不会被卡。
- **每天 6-8 小时完整时间块**：这是在职转行的人挤不出来的资源。

结论：你的卖点不是「我项目比你多」，而是「我能长期稳定地干活 + 我系统学过 + 我的项目能讲到最底层」。

### 3. 那两个「包装项目」怎么处理

**方案 A（推荐）：彻底降级，不进简历主区块**
简历上最多保留一行放进「其他经历」，或直接删掉。空出来的位置全部给你这 30 天的新项目。
如果面试官问「你本科做过什么科研」，标准答法：

> 「本科阶段跟老师做过 XX 方向的科研训练，主要是文献调研和已有方法的复现，没有形成可交付的成果。所以我把重心放在了后面这段自己从零搭的工程上。」

这句话 100% 安全，而且通常会加分——它说明你有自知之明，不是吹牛的人。

**方案 B：回炉重做（仅在主线项目完成之后）**
第 3 周学完后，回头把其中一个项目用你学到的东西真正跑通：读懂原代码 → 重构 → 跑出结果 → 加一个你的改进点 → 写一份对比实验。成本约 3-4 天，把它从「拿来的」变成「我改过的」。

**方案 C：绝对不要做的**
不要把包装项目写得比新项目还详细，不要伪造指标。面试深挖 3 轮必崩，崩一次这家公司所有岗都进不去了。

### 4. 投递时间：不要等「学完」

- **11/11（第 3 周结束）开始投第一批**——此时你手上有能跑的 RAG + 一个 Agent，够撑一场 30 分钟面试。
- **11/18 起进入密集投递期**。
- 面试本身就是最强的学习：被问住的问题当晚补掉，下一场就不会再被问住。
- 首批先投 5-8 家你不太想去的「练手场」，把面试状态跑热，再投目标公司。

## 三、主线项目验收标准

不管最后做哪个项目，必须满足这 8 条，缺一条面试就会露馅：

1. **完整链路**：数据 → 切分 → 索引 → 检索 → 重排 → 生成 → 引用，每一环自己写
2. **可量化**：至少 3 组对照实验的数字（不能只有「效果变好了」）
3. **有失败分析**：能说出「它在什么情况下会失败，我当时怎么修的」
4. **能讲清取舍**：每个技术选型的 alternatives 和你为什么没选（为什么 HNSW 不选 IVF？为什么 RRF 不加权求和？）
5. **能本地跑**：`git clone` + `uv sync` + 一条命令跑起来
6. **有 Agent 成分**：不是纯 pipeline，至少有路由 / 规划 / 自检中的一个
7. **有 MCP 或工具协议**：至少一个工具通过 MCP 暴露
8. **代码质量**：有类型标注、有架构图、commit 历史是渐进的（不要一次 commit 2000 行）

## 六、六个必须提醒你的坑

1. **LangChain 版本坑（最现实的一个）**：你装的是 langchain 1.4.6，而 all-in-rag 教程大概率基于 0.3.x。1.x 有 breaking change，教程代码直接跑大概率报错。
   **策略**：教程看思路，代码按新 API 自己写，报错直接发我。更稳的做法是核心链路（切分 / 检索 / 融合 / 重排）自己手写，框架只用在编排层——这样你面试讲起来也更硬。
2. **别陷入教程收集癖**：三份资料 200+ 篇，你只能读约 40 篇。每天先做产出物，再看文档。
3. **别在 Week 1 卡死**：某个概念卡超过 2 小时就记下来跳过，继续走，晚上或第二天问。
4. **不要做 GraphRAG / 多模态 / 微调**：一个月内这些的投入产出比都是负的。
5. **每天 commit**，哪怕只改了 README。连续 30 天的绿点本身就是简历素材。
6. **别跟同学比投递进度**。他们投得早，你追不上「时间」，但你能追上「深度」。面试官一天看 20 份简历，能讲到底的那份才会被记住。
